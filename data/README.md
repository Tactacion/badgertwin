# LoopWatch data

- `raw/`: untouched downloads (Open-Meteo weather, OpenStreetMap, NIH RePORTER, NSF, FRED diesel, FP&M facility list, article text).
- `curated/`: cleaned public facts with `source_url` and `verified` columns.
- `simulated/`: generated by `scripts/build_twin_data.py` (seed 1980). It is SIMULATED, so label it on screen.

Rebuild with: `.venv/bin/python scripts/build_twin_data.py`
Full guide: `../LOOPWATCH_C3_PLAYBOOK.md`
